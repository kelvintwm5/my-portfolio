## Problem

What problem does this solve? Why does it matter? What's the gap in existing tools or workflows?

## Approach

How did you think about the solution space? What were the key architectural or design decisions and why?

## Solution

What did you actually build? How does it work?

## Systems Thinking

### Dependencies
- List external systems, APIs, or components this depends on
- Note failure modes that propagate from each dependency

### Constraints
- Technical or operational limits that shaped the design
- What the system intentionally doesn't do

### Edge Cases
- Known edge cases and how they're handled (or not yet handled)

## Outcome

What happened after you shipped it? Quantitative results, qualitative signals, user feedback.

## Learnings

- What would you do differently?
- What surprised you?
- What's the next iteration?
